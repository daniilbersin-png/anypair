Сердце системы

Три уровня оракула

Честно: не у всего есть рыночная цена. Поэтому каждый актив имеет свой источник — и он всегда виден трейдеру.

УРОВЕНЬ 01

Реальный фид

✓ On-chain verified

Актив имеет настоящий рынок — цену тянем по API и пушим в оракул на BNB.

  • Скины CS2 → Steam Market API
  • Покемон / TCG → индекс PSA / TCGplayer
  • Золото, нефть, уголь, пиломатериалы → сырьевые фиды
  • Крипта → Chainlink / Binance Oracle
УРОВЕНЬ 02

Комьюнити-индекс

◆ DAO-managed

Рынок есть, но раздроблен или неликвиден. Цену задаёт голосование стейкеров + споты.

  • Солнечная энергия (kWh по регионам)
  • Локальные товары, куриные крылья 🍗
  • Редкие коллекционки без единого рынка
  • Спорные активы → медиана голосов
УРОВЕНЬ 03

Чистый ларп

☺ For the memes

Цены нет и быть не может — но идея топовая. Псевдо-фид на честном random walk + сид.

  • «Уровень воды в реке Волге»
  • Абстракции: настроение рынка, вайб
  • Всё помечено ярлыком LARP — без обмана
  • Задача одна: завируситься 🚀
