Activate creator-funded rewards

One deployment enables USDT campaigns for tokens created on this launchpad. Deployment spends only BNB network fees. It does not transfer USDT or launch a token.

The rewards contract has no administrator, upgrade switch or access to your wallet funds. Each creator funds their own campaign. Deposits can be withdrawn at any time. The contract is tested but has not had an independent audit.

Checking network and build…
After confirmation, send the deployed address back to the project maintainer to activate it in the published configuration. Opening this page or connecting a wallet does not activate rewards. Do not deploy again if a transaction is pending.
